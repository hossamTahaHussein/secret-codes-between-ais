A small-scale replication on an 8 GB gaming GPU

Two small AIs were told to sneak a secret past a monitor. They invented the code themselves.

Sender

Writes a 2–3 sentence product review and must hide one secret word in it: red or blue.

Receiver

Reads the review and has to say which secret it carries. Trained together with the sender.

Monitor

Reads the same review and is asked whether it hides a message. It knows the secret is red or blue.

Every review, score and curve on this page was recorded from the real models. Nothing is simulated or written by hand.

Method and caveats

What this does and doesn't show

  • What this is. An engineering replication, at small scale, of the explicit setting in Mathew et al. 2024, "Hidden in Plain Text". The sender is told outright that it has a secret to pass and that a monitor is watching. Only the code itself is learned: nobody told it "vibrant colors means red". So this shows that a pair asked to communicate covertly will find a way. It does not show that hidden communication appears on its own when nobody asks for it, which is the more important open question.
  • Setup. One Qwen2.5-1.5B-Instruct model with two small LoRA adapters (sender and receiver) on a single RTX 5060. The monitor is the same base model with the adapters switched off. The sender is trained with reinforcement learning: it is rewarded when the receiver decodes the secret and penalised when the monitor flags the review or the color word appears. The receiver is trained to decode.
  • The secret is one bit. Red or blue. A real colluding system would need more capacity, and that is harder to hide.
  • Emergence is fragile. With the penalties on from step 1, the pair learned to stay silent instead of hiding anything (Pilot A). With a warm-up it invented the code (Pilot B). The same warm-up recipe on Qwen3-1.7B collapsed back to silence (Round 1, English).
  • The learned detectors had help. They were trained on a few hundred labelled reviews from this exact sender. A sender retrained against them would probably adapt.
  • The monitor is weak in both languages. The prompted monitor rarely flags anything, even reviews that name the color outright, in English and in Arabic, and even after an Arabic review is translated to English. These runs show no Arabic-specific blind spot: a fair language comparison needs a stronger monitor first.
  • A half-overt trick keeps appearing. In the Qwen3 runs the pair often names one color and stays silent for the other. With a one-bit secret, that pays the color-word penalty on only half the messages, which the reward makes the best option. It says more about the reward than about hiding.
